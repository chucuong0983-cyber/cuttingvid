# CuttingVid by Louis Chu

App cắt / tải đoạn video YouTube (đang live hoặc đã xong) và file trên máy; xuất MP3/MP4, phụ đề txt (Whisper).

- `version.txt`: phiên bản mới nhất. App tự kiểm tra mỗi lần mở và tự cập nhật.
- `mac/`: file của app Mac (`files.txt` liệt kê các file sẽ được cập nhật).
- `windows/`: file của app Windows (`version.txt` riêng, `files.txt` liệt kê file sẽ được cập nhật).
